# takutakuja0803-del.github.io
TAKUMI Lab website and app support pages.

## Adding an app

Before editing, read `AGENTS.md` and `TAKUMI_DESIGN.md`, then compare the
existing app pages. Keep the shared navigation, `styles.css`, layout, and
relative paths used by SwifKit and Smart GPA. Add an app detail page with its
overview, confirmed features, and an Availability section that states its
verified release status. Add an app-specific Support page once the responsible
contact route is confirmed. Link a Privacy Policy only after the developer or
responsible operator confirms the app's actual collection, storage, and sharing practices;
do not copy another app's policy. Do not invent an App Store URL or mark an
unconfirmed app as released.

For TAKUMI Lab's own apps, use the existing site design and page patterns.
For client-commissioned apps, confirm the developer, operator, support contact,
and privacy-policy owner for that app before publishing those details. A
client app may also need its own Support page, but TAKUMI Lab must not be
assumed to be the client's support contact. Avoid dead links for pages that
have not been created.
